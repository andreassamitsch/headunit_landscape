# Issue #140 – 13.7.73

## Root cause correction
The earlier 13.7.72 bridge fix made Browse playlist cards touchable, but the user-visible failure is one level deeper: after opening the playlist, `OnlinePlaylistScreen` song rows still used `combinedClickable` below the fixed Dudu7 right-pane gesture layer. Keyboard activation could therefore work while physical touch on a playlist song did not start playback.

## 13.7.73 change
Embedded playlist song rows now register their real `boundsInRoot()` with the existing `RightPaneScrollBridge`. A non-drag touch is dispatched to the same `onSongClick` callback that builds `YouTubePlaylistQueue` with the selected `startIndex`. Outside the Dudu7 embedded pane, standard MetroList keeps the existing `combinedClickable` behavior.

## Release gate
13.7.73 may be exposed through the integrated updater only after the blocking workflow passes standard compile, Dudu7 unit tests, ARM APK build, APK metadata/signature/ABI verification, and the source regression invariant. Issue #140 remains open until the real Dudu7 device confirms touch selection and playback.
